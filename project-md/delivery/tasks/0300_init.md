# 0300: Init

`thunderjar init` scaffolds the `.thunderjar/` configuration folder in a project, tested against the first scenario: an empty project.

Also adds the library entry point, so a scaffolded project resolves `thunderjar`.

From row 1. See [planned reapplication](../../research/planned-reapplication.md), step 3.

## Version bump type

minor

## Artifacts

- `thunderjar init` fills in the existing stub
- The `thunderjar` library entry point
- Scenario `fixtures/01_unitialised/0101_empty_project/`

```
$ thunderjar init
Created .thunderjar/
Created .thunderjar/package.json
Created .thunderjar/tsconfig.json
...
```
